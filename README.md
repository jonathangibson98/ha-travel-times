# Jon's Home Assistant Add-ons

[![Add repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fjonathangibson98%2Fha-travel-times)

## Add-ons
- **Travel Times** - near real-time Waze drive-time sensors from each person to each destination.

## Install
Settings > Add-ons > Add-on store > three dots > Repositories > paste
`https://github.com/jonathangibson98/ha-travel-times` > Add.
